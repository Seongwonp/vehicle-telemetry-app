## 3. 조사로 확정한 결론 (다시 조사하지 않는다)

- **C안 선택 근거**: fleet app management(CC BY 4.0)의 구조만 차용. 색 띠 머리·알약 탭은 원본과 닮아 빼고 앱 토큰 유지. 나머지 후보(Pitstop·Tracking UI Kit·sensor·My Car)는 부적합 또는 평가 불가 — 계획 문서 표.
- **320px·글자 1.5배에서 옛 보조 지표 그리드가 3~4px 넘쳤다** — 구성 요소 단독 검사로는 안 잡혀 `test/dashboard_layout_test.dart`(화면 72조합)를 만들었다.
- `ThemeData(fontFamilyFallback:)`는 기본 텍스트 테마에만 적용된다 — Manrope 텍스트 테마에 `.apply(fontFamilyFallback:)`로 직접 걸어야 한글이 □가 아니다(`app_theme.dart`).
- 글꼴 번들 후 골든 16장이 픽셀 그대로 → 테스트와 앱의 한글 글꼴이 같다.
- `assets/logo.png`는 **체크무늬가 이미지에 박혀 있어** 쓰지 않는다. 투명 로고는 `assets/logo_icon.png`.
- 이 PC에서 **adb 기본 포트 5037이 Windows 예약 범위(4994–5093)** 라 adb가 안 뜬다 → `ANDROID_ADB_SERVER_PORT=15037`. 시스템 설정은 바꾸지 않았다.
