## 2. 완료한 것과 근거

### 2-1. 골든 테스트 글꼴 (오전)

- **원인**: google_fonts는 글꼴 이름을 `Manrope_regular`·`Manrope_700`처럼 굵기별로 쓰는데 테스트는 `'Manrope'`에만 시스템 글꼴을
  물려 라틴·숫자가 테스트 기본 글꼴(□)로 그려졌다. 아이콘 글꼴도 없었다. 오프라인 "실패"는 google_fonts가 에셋에서 Manrope를 못 찾아 던진 예외였다.
  근거: 앱 복사본에서 굵기별 이름 등록 유무를 나란히 렌더한 실험(스크래치, 저장소 밖).
- **수정**: Manrope 5종을 앱 에셋으로 번들(출처 `aaronbell/manrope` `6f81ebe`, OFL 내장), 한글은 테스트 전용 나눔고딕(출처 `google/fonts` `133ccbe`, OFL.txt).
- **결과**: 재생성 8장 전부 확인(숫자·영문·아이콘·"N분 전"만 바뀜), 일반 비교 8/8, 전체 `flutter test` 255 통과·1 skip(골든 태그), analyze 0, format 변경 0.
  google_fonts 로드 오류 0회.

### 2-2. 밝은 랜딩 로고 누락 (오후)

- **재현**: 전체 스위트에서는 `landing_360`(라이트)만 로고가 비고 `landing_dark_360`(다크)에는 나왔다. **각각 단독 실행하면 둘 다 비었다.**
  테마 문제가 아니라 **순서 의존**이다 — 이미지 에셋은 fake_async 밖의 실제 비동기로 읽고 디코딩되어 pump로 끝나지 않고,
  첫 이미지 테스트가 시작한 로딩이 캐시에 남아 다음 테스트에서만 보였다. 예전 스냅샷에도 같은 차이가 있었다.
- **수정**: `_snap`에서 `tester.runAsync` 안에 화면의 `Image`를 `precacheImage`한 뒤 pump한다.
- **검증**: 랜딩 두 장만 재생성해 직접 확인(라이트에 로고 표시) → **라이트·다크를 각각 단독으로 일반 비교 모드 통과** →
  골든 스위트 전체 일반 비교 **3회 연속 8/8**. 이후 format·analyze 0. 전체 `flutter test`는 이 변경이 기본 실행에서 skip되는 파일뿐이라 다시 돌리지 않았다.

### 2-3. CI의 골든 비교

- **확인한 사실**: 기존 CI(`verify`, ubuntu)는 `flutter test`만 돌려 골든이 **skip**된다 — 골든 비교는 CI에서 한 번도 돌지 않았다.
- **추가**: `golden` 잡 — `windows-2022`, Flutter 3.41.6 고정, `flutter test test/golden --run-skipped`(**`--update-goldens` 없음**),
  실패 시 `test/golden/failures/`를 artifact로. 기준 이미지는 Windows에서 만들었고 글꼴 래스터화가 OS마다 달라 Linux에서는 비교하지 않는다.
- **글꼴 파일이 checkout에 들어가는가**: `git check-ignore`로 `assets/google_fonts/`·`test/fonts/`가 무시되지 않음을 확인. 출처·라이선스는
  `test/fonts/SOURCE.md`와 `docs/design-system.md`에 연결했다.

## 4. 다음 실행 명령과 성공 기준

```powershell
flutter pub get
dart format --output=none --set-exit-if-changed lib test integration_test
flutter analyze
flutter test
flutter test test/golden --run-skipped
```

성공: format 변경 0, analyze `No issues found!`, `flutter test` 전부 통과(골든 1건 skip), 골든 비교 `+8: All tests passed!`,
출력에 `google_fonts was unable` 없음.

골든 기준 이미지를 **의도적으로** 바꿀 때만:

```powershell
flutter test test/golden --run-skipped --update-goldens
```

그 뒤 `test/golden/snapshots/*.png` 8장을 전부 열어 **예상한 변경만** 있는지 보고, 일반 비교를 다시 통과시킨다.
